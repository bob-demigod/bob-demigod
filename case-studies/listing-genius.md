# Listing Genius

Prompt library and generator for real estate agents, brokers, and investors.

## Problem

Agents repeat the same listing, follow-up, and investor emails. They needed a searchable library of strong prompts and a way to fill one in without starting from a blank page.

## What I built

- Landing page and pricing page
- Library of production seed prompts across several categories, with search and filters
- Generator that turns a short brief into a filled template
- One-tap handoff into ChatGPT, Claude, or Grok
- Favorites and history on the device, with a Supabase schema ready for accounts
- Admin scaffold and a PWA manifest

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, Supabase (auth, Postgres, full-text search), Stripe subscriptions prepared, Zustand.

## Status

Private commercial product. This page does not include environment values or the database schema.

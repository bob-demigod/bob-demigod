# Aetheria

Integrated personality, character, and purpose profile. Web app plus an Android shell.

## Problem

People and practitioners wanted one workspace for a structured self-report, a readable synthesis, and optional follow-up conversation. The product had to stay explicit that it is not a clinical diagnosis.

## What I built

- Assessment wizard with consent, save and resume, and a written Essence report
- Scoring and synthesis for preference-style inventories, non-diagnostic screening, and symbolic modules (numerology and a natal approximation)
- Profile-aware chat companion ("Aether") behind a plan gate
- Journal prompts drawn from the report
- Practitioner workspace: client list, consent flags, linked reports, session notes
- Account sync and Stripe plans (Free, Personal, Professional, Licensed)
- Capacitor Android packaging, with an iOS path prepared for a Mac build

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, Neon Postgres, Drizzle, Stripe Checkout and webhooks, Vercel AI SDK with xAI, Capacitor.

## Status

Private commercial build. Store listing copy and mobile packaging exist. This page does not include keys, price IDs, or the production host.

## Disclaimer

Not clinical. It does not diagnose. Preference items are original, not an official instrument. Symbolic modules are labeled as symbolic. Elevated screening tiers point people toward professional care.
